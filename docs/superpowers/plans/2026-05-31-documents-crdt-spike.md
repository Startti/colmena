# Documents CRDT Spike — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a 2-3 week time-boxed spike that validates whether the hybrid CRDT path (Univer in browser + Yrs in colmena + Yrs→IR projection) is technically viable, by exercising risks R1 (multi-peer convergence over y-websocket), R2 (projection cost/stability), and R5 (`.xlsx` ingestion fidelity).

**Architecture:** New isolated module `dag_engine::spike` exposing two CLI subcommands (`spike-yws` server + `spike-agent` client). The server holds a `DashMap<ArtifactId, yrs::Doc>`, serves static HTML loading Univer from CDN, speaks the Yjs sync protocol over a WebSocket endpoint, projects Yrs state to a minimal IR JSON, and dumps to `/tmp/spike/` after each batch. The agent peer connects either via WebSocket (the path that validates R1) or via an internal HTTP POST for sanity checks. All spike code lives under `dag_engine::spike` so it does NOT pollute production paths and can be deleted as a single PR after the verdict.

**Tech Stack:** Rust 1.95, axum 0.7 (HTTP + WS), `yrs` 0.21 (CRDT runtime), `y-sync` 0.4 (Yjs sync v1 protocol on top of yrs), `tokio-tungstenite` 0.21 (agent WS client), Univer ≥ 0.2 from `unpkg.com` CDN, `y-websocket` 1.5 JS client from `unpkg.com`. Spec: [`docs/superpowers/specs/2026-05-31-documents-crdt-spike-design.md`](../specs/2026-05-31-documents-crdt-spike-design.md).

```rust
//! In-memory registry of `yrs::Doc` keyed by artifact id.
//!
//! Used by the spike server to look up (or lazily create) the CRDT
//! document for an artifact. Backed by `DashMap` for concurrent access
//! without an outer lock.

use dashmap::DashMap;
use std::sync::Arc;
use yrs::Doc;

#[derive(Default)]
pub struct DocRegistry {
    docs: DashMap<String, Arc<Doc>>,
}

impl DocRegistry {
    pub fn new() -> Self {
        Self {
            docs: DashMap::new(),
        }
    }

    /// Returns the doc for `artifact_id`, creating an empty one if absent.
    pub fn get_or_create(&self, artifact_id: &str) -> Arc<Doc> {
        if let Some(existing) = self.docs.get(artifact_id) {
            return existing.clone();
        }
        let doc = Arc::new(Doc::new());
        self.docs.insert(artifact_id.to_string(), doc.clone());
        doc
    }

    pub fn get(&self, artifact_id: &str) -> Option<Arc<Doc>> {
        self.docs.get(artifact_id).map(|r| r.value().clone())
    }

    pub fn len(&self) -> usize {
        self.docs.len()
    }
}
```

```rust
//! Pure projection from a `yrs::Doc` (Excel-shaped) into the minimal IR JSON
//! used by colmena's documents library. Read-only. Spec §4.3.

use serde_json::{json, Value};
use yrs::{Array, Doc, Map, ReadTxn, Transact};

/// Project the current state of `doc` to the minimal IR JSON.
///
/// Returns `{ "sheets": [ { "id", "name", "cells": { addr: value } } ] }`.
/// Cells whose payload is malformed (missing `v` or `t`) are skipped.
pub fn project(doc: &Doc) -> Value {
    let txn = doc.transact();
    let workbook = match txn.get_map("workbook") {
        Some(m) => m,
        None => return json!({ "sheets": [] }),
    };
    let sheets_arr = match workbook.get(&txn, "sheets") {
        Some(yrs::Out::YArray(a)) => a,
        _ => return json!({ "sheets": [] }),
    };

    let mut sheets_out = Vec::with_capacity(sheets_arr.len(&txn) as usize);
    for i in 0..sheets_arr.len(&txn) {
        let sheet_map = match sheets_arr.get(&txn, i) {
            Some(yrs::Out::YMap(m)) => m,
            _ => continue,
        };
        let id = sheet_map
            .get(&txn, "id")
            .and_then(|v| match v {
                yrs::Out::Any(yrs::Any::String(s)) => Some(s.to_string()),
                _ => None,
            })
            .unwrap_or_default();
        let name = sheet_map
            .get(&txn, "name")
            .and_then(|v| match v {
                yrs::Out::Any(yrs::Any::String(s)) => Some(s.to_string()),
                _ => None,
            })
            .unwrap_or_default();

        let cells_map = match sheet_map.get(&txn, "cells") {
            Some(yrs::Out::YMap(m)) => m,
            _ => {
                sheets_out.push(json!({ "id": id, "name": name, "cells": {} }));
                continue;
            }
        };

        let mut cells_out = serde_json::Map::new();
        for (addr, cell_val) in cells_map.iter(&txn) {
            let cell_map = match cell_val {
                yrs::Out::YMap(m) => m,
                _ => continue,
            };
            let v = match cell_map.get(&txn, "v") {
                Some(yrs::Out::Any(any)) => any_to_json(&any),
                _ => continue,
            };
            cells_out.insert(addr.to_string(), v);
        }
        sheets_out.push(json!({ "id": id, "name": name, "cells": cells_out }));
    }

    json!({ "sheets": sheets_out })
}

fn any_to_json(any: &yrs::Any) -> Value {
    match any {
        yrs::Any::Null | yrs::Any::Undefined => Value::Null,
        yrs::Any::Bool(b) => Value::Bool(*b),
        yrs::Any::Number(n) => json!(n),
        yrs::Any::BigInt(n) => json!(n),
        yrs::Any::String(s) => Value::String(s.to_string()),
        _ => Value::Null,
    }
}

}
```

## Task 5: Yjs sync v1 protocol over WebSocket

**Files:**

The Yjs sync v1 protocol has three message types (`sync_step1`, `sync_step2`, `update`) framed by a leading varint type byte. We use the `y-sync` crate to handle encoding/decoding so we don't reimplement the protocol.

- [ ] **Step 1: Write failing test — two docs exchanging messages converge**

Replace `yjs_protocol.rs` with:

```rust
//! Yjs sync v1 protocol bridge between an `axum::extract::ws::WebSocket`
//! and a `yrs::Doc`. Delegates wire-format work to the `y-sync` crate.
//!
//! Spec §4.1: this lets any Yjs client (Univer's `y-websocket` provider
//! or our own Rust `agent_peer`) sync with our server.

use anyhow::{anyhow, Result};
use axum::extract::ws::{Message, WebSocket};
use futures::{SinkExt, StreamExt};
use std::sync::Arc;
use yrs::{Doc, ReadTxn, Transact};

/// Drives a single WebSocket connection's sync with `doc`.
///
/// Steps:
///   1. Server sends sync_step1 (state vector) so the client can compute
///      its missing updates.
///   2. Each side responds with sync_step2 (the missing update) or
///      additional `update` messages.
///   3. Future incremental updates fan out via an `update_v1` observer.
pub async fn handle_socket(mut socket: WebSocket, doc: Arc<Doc>) -> Result<()> {
    use y_sync::sync::{Message as YMsg, MessageReader, Protocol, SyncMessage};
    let protocol = y_sync::sync::DefaultProtocol;

    // 1. Send our initial sync_step1.
    let sv = doc.transact().state_vector();
    let mut encoder = yrs::updates::encoder::EncoderV1::new();
    YMsg::Sync(SyncMessage::SyncStep1(sv))
        .encode(&mut encoder)
        .map_err(|e| anyhow!("encode sync_step1: {e:?}"))?;
    socket
        .send(Message::Binary(encoder.to_vec()))
        .await
        .map_err(|e| anyhow!("send sync_step1: {e}"))?;

    // 2. Subscribe to local updates so we forward them.
    //    NOTE: in production we'd hold the subscription guard; for the spike
    //    we leak it for the lifetime of the connection by storing it on the
    //    stack and never dropping until the handler returns.
    let (tx, mut rx) = tokio::sync::mpsc::unbounded_channel::<Vec<u8>>();
    let _sub = doc.observe_update_v1(move |_, evt| {
        let mut enc = yrs::updates::encoder::EncoderV1::new();
        if YMsg::Sync(SyncMessage::Update(evt.update.clone()))
            .encode(&mut enc)
            .is_ok()
        {
            let _ = tx.send(enc.to_vec());
        }
    })?;

    // 3. Concurrently read from socket and write outbound updates.
    loop {
        tokio::select! {
            outbound = rx.recv() => {
                match outbound {
                    Some(bytes) => {
                        if socket.send(Message::Binary(bytes)).await.is_err() {
                            break;
                        }
                    }
                    None => break,
                }
            }
            incoming = socket.next() => {
                let Some(msg) = incoming else { break };
                let Ok(msg) = msg else { break };
                let bytes = match msg {
                    Message::Binary(b) => b,
                    Message::Close(_) => break,
                    _ => continue,
                };
                let mut dec = yrs::updates::decoder::DecoderV1::from(&bytes[..]);
                let mut reader = MessageReader::new(&mut dec);
                while let Some(parsed) = reader.next() {
                    let parsed = parsed.map_err(|e| anyhow!("decode: {e:?}"))?;
                    if let Some(reply) = protocol.handle(&doc, parsed)
                        .map_err(|e| anyhow!("handle: {e:?}"))?
                    {
                        let mut enc = yrs::updates::encoder::EncoderV1::new();
                        reply.encode(&mut enc).map_err(|e| anyhow!("encode reply: {e:?}"))?;
                        if socket.send(Message::Binary(enc.to_vec())).await.is_err() {
                            return Ok(());
                        }
                    }
                }
            }
        }
    }
    Ok(())
}
```

```rust
async fn ws_handler(
    ws: WebSocketUpgrade,
    Path(artifact_id): Path<String>,
    State(state): State<SpikeState>,

    })

    }
```

```rust
//! Agent-peer mutations. WS-client variant added in Task 9; in-proc
//! variant here (used by `POST /spike/agent-op`).

use serde_json::Value;
use yrs::{Any, ArrayPrelim, Doc, Map, MapPrelim, Transact};

/// Sanity-check route: mutates the doc directly without going through WS.
///
/// Creates the workbook/sheets/cells structure on demand. Idempotent on
/// the sheet entry (looks up by `sheet_id`; creates if missing).
pub fn apply_set_cell_in_proc(doc: &Doc, sheet_id: &str, addr: &str, value: &Value) {
    let mut txn = doc.transact_mut();
    let workbook = txn.get_or_insert_map("workbook");
    let sheets_arr = match workbook.get(&txn, "sheets") {
        Some(yrs::Out::YArray(a)) => a,
        _ => workbook.insert(&mut txn, "sheets", ArrayPrelim::default()),
    };

    // Find sheet by id, or push a new one.
    let mut sheet_idx: Option<u32> = None;
    for i in 0..sheets_arr.len(&txn) {
        if let Some(yrs::Out::YMap(m)) = sheets_arr.get(&txn, i) {
            if let Some(yrs::Out::Any(yrs::Any::String(s))) = m.get(&txn, "id") {
                if s.as_ref() == sheet_id {
                    sheet_idx = Some(i);
                    break;
                }
            }
        }
    }
    let sheet = match sheet_idx {
        Some(i) => match sheets_arr.get(&txn, i).unwrap() {
            yrs::Out::YMap(m) => m,
            _ => unreachable!(),
        },
        None => {
            let new_sheet = sheets_arr.push_back(&mut txn, MapPrelim::default());
            new_sheet.insert(&mut txn, "id", sheet_id);
            new_sheet.insert(&mut txn, "name", sheet_id);
            new_sheet.insert(&mut txn, "cells", MapPrelim::default());
            new_sheet
        }
    };

    let cells = match sheet.get(&txn, "cells") {
        Some(yrs::Out::YMap(m)) => m,
        _ => sheet.insert(&mut txn, "cells", MapPrelim::default()),
    };

    let cell = cells.insert(&mut txn, addr, MapPrelim::default());
    let (any, type_tag) = json_to_any(value);
    cell.insert(&mut txn, "v", any);
    cell.insert(&mut txn, "t", type_tag);
}

fn json_to_any(v: &Value) -> (Any, &'static str) {
    match v {
        Value::String(s) => (Any::String(s.clone().into()), "s"),
        Value::Number(n) => (
            n.as_f64().map(Any::Number).unwrap_or(Any::Null),
            "n",
        ),
        Value::Bool(b) => (Any::Bool(*b), "b"),
        _ => (Any::Null, "s"),
    }
}
```

```rust
use anyhow::{anyhow, Result};
use tokio_tungstenite::tungstenite::Message as TMsg;
use y_sync::sync::{Message as YMsg, SyncMessage};

/// Connects to `url` as a Yjs client, applies `set_cell(sheet, addr, value)`
/// to a local `Doc`, and pushes the resulting update through the WS so
/// the server (and any other peers) converge.
pub async fn apply_set_cell_via_ws(
    url: &str,
    sheet_id: &str,
    addr: &str,
    value: &Value,
) -> Result<()> {
    use futures::{SinkExt, StreamExt};
    let (mut ws, _resp) = tokio_tungstenite::connect_async(url)
        .await
        .map_err(|e| anyhow!("connect: {e}"))?;

    let local = Doc::new();

    // Receive the server's sync_step1 and respond with sync_step2 (our diff
    // against their state vector). We also expect inbound updates.
    let server_sv = loop {
        match ws.next().await {
            Some(Ok(TMsg::Binary(bytes))) => {
                let mut dec = yrs::updates::decoder::DecoderV1::from(&bytes[..]);
                let mut reader = y_sync::sync::MessageReader::new(&mut dec);
                if let Some(parsed) = reader.next() {
                    let parsed = parsed.map_err(|e| anyhow!("decode initial: {e:?}"))?;
                    if let YMsg::Sync(SyncMessage::SyncStep1(sv)) = parsed {
                        break sv;
                    }
                }
            }
            Some(Ok(_)) => continue,
            other => return Err(anyhow!("unexpected ws frame: {other:?}")),
        }
    };

    // Apply mutation locally.
    apply_set_cell_in_proc(&local, sheet_id, addr, value);

    // Send our diff against the server's state vector.
    let diff = local.transact().encode_diff_v1(&server_sv);
    let mut enc = yrs::updates::encoder::EncoderV1::new();
    YMsg::Sync(SyncMessage::SyncStep2(diff))
        .encode(&mut enc)
        .map_err(|e| anyhow!("encode step2: {e:?}"))?;
    ws.send(TMsg::Binary(enc.to_vec()))
        .await
        .map_err(|e| anyhow!("send step2: {e}"))?;

    // Graceful close so the server's WS handler exits cleanly.
    ws.send(TMsg::Close(None)).await.ok();
    Ok(())
}
```
