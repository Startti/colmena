# src/libs/colmena/src/llm/application/attachment_catalog.rs

**Layer:** application  **Purpose:** Renders the per-session attachment catalog block prepended to the LLM node's system message, listing all registered attachments with metadata and usage hints in prose format (Plan A).

## Symbols

- `render_catalog` (pub fn) — Renders attachment catalog block from a list of ConversationAttachments; returns None if empty, Some(prose block) otherwise; output includes document_id, filename, mime, size, description, origin, registration timestamp, and canonical usage hints (load_attachment / $attachment:id).
- `humanize_origin` (fn) — Transforms origin strings for human readability (e.g., "generated_by:image_generation" → "generated by image_generation", "user_upload" → "uploaded by user").
- `human_size` (fn) — Formats optional byte counts as human-readable strings (B, KB, MB with one decimal place).
- `tests` (mod) — Test module containing unit tests for catalog rendering.
  - `mk` (fn) — Test helper factory that constructs a ConversationAttachment with fixed/default values for test cases.
  - `empty_list_returns_none` (test) — Verifies that an empty attachment list returns None.
  - `single_doc_renders_full_block` (test) — Verifies that a single attachment renders with all expected fields (id, filename, mime, size, description, origin, usage hints).
  - `generated_origin_humanizes_correctly` (test) — Verifies that "generated_by:*" origin strings are humanized correctly.
