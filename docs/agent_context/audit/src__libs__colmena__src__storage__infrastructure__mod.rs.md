# src/libs/colmena/src/storage/infrastructure/mod.rs

**Layer:** infrastructure  
**Purpose:** Module index that declares and re-exports the three output storage adapter implementations (HTTP callback, local cache, local HTTP).

## Symbols

- `http_callback_adapter` (mod, pub) — Submodule containing `HttpCallbackStorageAdapter` implementation
- `local_cache_adapter` (mod, pub) — Submodule containing `LocalCacheStorageAdapter` implementation
- `local_http_adapter` (mod, pub) — Submodule containing `LocalHttpStorageAdapter` implementation
- `HttpCallbackStorageAdapter` (type, pub) — Re-exported adapter for HTTP callback-based storage
- `LocalCacheStorageAdapter` (type, pub) — Re-exported adapter for local file cache storage
- `LocalHttpStorageAdapter` (type, pub) — Re-exported adapter for local HTTP storage

## File-level notes

None — file is clean and straightforward as a module index.
