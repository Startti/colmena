To give an API a link to a document instead of its content (a field such as `image_url` or `file_url`), pass the string "$attachment_url:<document_id>" as the whole value of that field in the JSON body of an `http_request` tool, with a `document_id` from the catalog. The engine replaces it with a short-lived link to the stored file just before the request goes out; you never see the link, and the tool's result shows the placeholder instead. It works only with a tool whose address is fixed: a tool that asks you for its `base_url` or `endpoint` refuses it. For the file's content, use "$attachment:<document_id>".
