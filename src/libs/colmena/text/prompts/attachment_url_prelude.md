To give an API a link to a document instead of its content (a field such as `image_url` or `file_url`), pass the string "$attachment_url:<document_id>" as the whole value of that field in the JSON body of a tool that sends an HTTP request, with a `document_id` from the catalog. Just before the request goes out, the engine replaces it with a short-lived link to the stored file, sent only to the tool's fixed address; you never see the link, and the tool's result shows the placeholder instead. A tool that asks you for its `base_url`, `endpoint` or a `Host` header refuses it. For the file's content, use "$attachment:<document_id>".
